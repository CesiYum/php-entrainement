# 01 — Carte de joueur

**Notions :** echo, variables, types  
**Situation :** Un jeu affiche la fiche d’un nouveau personnage.

## Consignes

Déclarez son pseudo, son niveau entier, son énergie flottante et son état actif. Affichez une phrase de présentation, puis le type de chaque donnée avec `get_debug_type`. Comparez un niveau numérique avec le texte représentant ce niveau.

## Vérification

Le programme affiche les quatre types et la comparaison stricte vaut `false`.

Depuis la racine du projet, lancez `php 01-carte-joueur/index.php`.
