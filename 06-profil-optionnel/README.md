# 06 — Profil incomplet

**Notions :** null, ??, ?->, isset, array_key_exists  
**Situation :** Un profil peut avoir un surnom et une date de dernière connexion.

## Consignes

Affichez le surnom s’il existe, sinon le nom. Comparez `isset` et `array_key_exists` pour une clé qui vaut `null`. Formatez la dernière connexion avec `?->` ou affichez « jamais ».

## Vérification

Le surnom de repli est Mira ; la clé existe mais `isset` renvoie `false`.

Depuis la racine du projet, lancez `php 06-profil-optionnel/index.php`.
